# Analysis

This folder contains the statistical analysis materials for the antenatal care quality and satisfaction project.

The analysis was initially conducted using IBM SPSS Statistics. Selected analyses will also be reproduced using R as part of the development of reproducible healthcare data analysis skills.

## Planned Analysis

- Data preparation and cleaning
- Descriptive statistics
- Reliability analysis
- Quality of care scoring
- Satisfaction scoring
- Correlation analysis
- Chi-square tests
- Data visualization
- Reproducible analysis using R
