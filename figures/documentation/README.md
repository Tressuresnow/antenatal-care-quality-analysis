# Documentation

This folder contains supporting documentation for the antenatal care quality and satisfaction analysis project.

## Contents

- Study background
- Research objectives
- Methodology summary
- Variable descriptions
- Data collection information
- Statistical analysis approach

## Research Area

The project focuses on assessing the quality of antenatal care services and client satisfaction among pregnant women attending selected primary healthcare centres.

## Notes

Participant-level data are not included in this repository in order to protect privacy and maintain ethical standards.
